# Dileep & Vaishnavi Wedding Website

A simple wedding invitation website for GitHub Pages.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `Dileep-Vaishnavi-Wedding`.
2. Upload **all files and folders** from this folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. GitHub will provide your public wedding website address.

The site is mobile-friendly and includes an August 26, 2026 countdown, English/Telugu text, and the invitation image.
